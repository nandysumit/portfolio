Case Studies

BFSI · HRMS · AI · SaaS
Legacy-to-SaaS HRMS Transformation for India's Largest Public Sector Bank
Enterprise HRMS · 2025
Challenge

One of India's largest public sector banks — managing payroll, pension, claims, transfers, and core HR for 250K+ employees and 350K+ pensioners across 150+ HR services — was operating on fragmented legacy systems with no structured audit framework, accumulating technical debt and ad-hoc enhancement backlogs with no governance in place.

Approach

Led structured migration of legacy HR data into an enterprise SaaS platform, establishing clean data governance and end-to-end traceability. Introduced formal documentation, SOP frameworks, and approval processes for all enhancements and bug fixes, enabling audit-ready closures. Established target operating models and multi-vendor governance. Developed an AI Roadmap and deployed AI Agents for key transactional processes. Built an AI-powered ticketing tool to prioritise, route, and resolve HR service requests. Designed persona-based dashboards for leadership decision-making.

Outcome

40%+ reduction in manual payroll intervention. Zero-error, audit-ready processing environment established across one of India's most complex BFSI payroll landscapes. Governance frameworks significantly improved issue resolution predictability. AI roadmap approved by senior leadership for phased deployment across 600K+ users and 150+ HR services.

40%+ Manual Reduction 600K+ Users 150+ HR Services AI Roadmap Delivered Audit-Ready Ops

SAP HCM · Re-implementation · Automation · Mining
SAP R/3 to ECC 6.0 Re-implementation: From 90% Custom to 95% Standard
Global Mining Corporation · Singapore HQ · Full Re-implementation
Challenge

One of the world's largest mining corporations — headquartered in Singapore — was running a heavily customised SAP R/3 4.7 landscape (90% custom code), creating unsustainable maintenance overhead. The objective was a full re-implementation to SAP ECC 6.0 targeting 95% standard solution — requiring complex data migration, configuration translation, and validated parallel run cycles across a massive global footprint.

Approach

Led the re-implementation from design through go-live. Co-developed an automated migration tool with the technical team — reading legacy system values, validating target system configuration, applying translation rules, and updating the target system automatically. This eliminated manual data mapping and enabled high-frequency parallel run cycles for robust go-live validation.

Outcome

Automated tool reduced manual effort by 85+ hours and enabled 20+ parallel runs — providing the rigour needed for confident go-live sign-off. Successfully transitioned from 90% custom to 95% standard SAP ECC 6.0, dramatically reducing future maintenance burden and improving system sustainability.

85+ Hours Saved 20+ Parallel Runs 95% Standard Solution Automated Migration Tool

Global Mining Corporation · South Africa HQ · Support Transition

Outcome

Seamless transition of full SAP HCM support to the India delivery centre within agreed timeline. Significant reduction in average resolution time through the scenario database. Predictive volume tool enabled accurate monthly resourcing — eliminating reactive staffing and improving budget predictability across the engagement.

SAP HCM · Data Migration · 160+ Countries · Pharma
Mass Data Migration for a Global Pharma Giant Across 160+ Countries
North American Pharma Enterprise · Global HCM Implementation
Challenge

A North American pharma giant implementing SAP HCM required mass data migration across 160+ countries. The standard SAP Legacy System Migration Workbench lacked the filtering and validation precision needed at this scale. Bad data was causing failed loads, rework cycles, extended timelines, and quality risks at go-live.

Approach

Developed custom coding within the Legacy System Migration Workbench — adding intelligent filtering logic that identified, categorised, and separated bad data before load execution. Error categorisation enabled the client to quickly understand, fix, and reload data with precision. Migration was structured by geography ensuring controlled, verifiable batch execution with full reconciliation at each stage.

Outcome

Overall data load time reduced significantly. Error categorisation enabled the client to fix data issues rapidly and reload without rework cycles. Clean, reconciled HR data delivered across 160+ countries — providing a high-quality foundation for go-live and eliminating data-related post-live defects.

160+ Countries Reduced Load Time Custom Migration Logic Clean Go-live Data
